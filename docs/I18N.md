# Internationalization (FR/EN)

DeckEdge ships French and English UI text through a small client-side translation layer.

## How it works

- `i18n.js` is served by the backend and loaded by the mobile deck and, in later phases, the Studio.
- The initial language is `localStorage["deckedge.lang"]` when valid; otherwise the browser language selects French for `fr-*` and English for everything else.
- Static markup uses data attributes:
  - `data-i18n="key"` for text content
  - `data-i18n-placeholder="key"` for placeholders
  - `data-i18n-title="key"` for tooltips
  - `data-i18n-aria-label="key"` for accessible names
- Dynamic strings use `I18n.t("key", {count})`.
- `I18n.setLanguage("fr" | "en")` saves the choice, updates the DOM and notifies listeners registered with `I18n.onChange`.
- The mobile deck exposes an `EN`/`FR` button next to the profile tabs.

## Adding a string

1. Add the key to both `fr` and `en` tables in `i18n.js`.
2. Use `data-i18n` for static HTML or `I18n.t` in JavaScript.
3. Run `tests/i18n.cjs` and the regular Playwright suite.

## Rollout plan

1. Foundation and mobile deck (current).
2. Studio web UI.
3. C# tray, settings, dialogs and server/user-facing messages.
4. Repository documentation and code comments translated to English.

French UI remains the default for French browsers. Existing saved profiles and configuration files are language-neutral.
