# Internationalization (FR/EN)

DeckEdge ships French and English UI text through a small client-side translation layer.

## How it works

- `i18n.js` is served by the backend and loaded by the mobile deck and Studio.
- The initial language is `localStorage["deckedge.lang"]` when valid; otherwise the browser language selects French for `fr-*` and English for everything else.
- Static UI uses `data-i18n` keys or the legacy French-to-English map for the Studio, which is applied on render and language changes with a guarded `MutationObserver`.
- The Studio exposes a compact `FR`/`EN` selector in the header; the mobile deck has an `EN`/`FR` button next to the profile tabs.
- `?lang=fr` and `?lang=en` can force a language for a link or a test; the parameter is removed from the address after applying it.
- The selected language is mirrored to the `deckedge_lang` cookie so server-rendered pairing pages and API errors follow the same language. Without a cookie, the server uses the first `Accept-Language` value (French for `fr-*`, English otherwise).
- Static markup uses data attributes:
  - `data-i18n="key"` for text content
  - `data-i18n-placeholder="key"` for placeholders
  - `data-i18n-title="key"` for tooltips
  - `data-i18n-aria-label="key"` for accessible names
- Dynamic strings use `I18n.t("key", {count})`.
- `I18n.setLanguage("fr" | "en")` saves the choice, updates the DOM and notifies listeners registered with `I18n.onChange`.
- The mobile deck exposes an `EN`/`FR` button next to the profile tabs.

## Adding a string

1. Add the key to both `fr` and `en` tables in `i18n.js`.
2. Use `data-i18n` for static HTML or `I18n.t` in JavaScript.
3. Run `tests/i18n.cjs` and the regular Playwright suite.

## Windows application

- `desktop/UiText.cs` holds the French-to-English dictionary used by the tray window, settings form, phone dialog, color picker and message boxes.
- `AppPreferences.Language` stores `"fr"` or `"en"` in `app-settings.json`; new installs follow the Windows UI language.
- The settings form exposes a language selector and applies the choice immediately; cancelling restores the previous language.
- `UiText.Translate` walks controls, tooltips and menu items and restores the original French text when switching back. Dynamic statuses call `UiText.T` or `UiText.F`.
- User content such as profile names, key labels and installed application names is never translated.
- `tests/run-csharp-smoke.ps1` checks the dictionary, one-way translation and FR/EN restoration.

## Rollout plan

1. Foundation and mobile deck.
2. Studio web UI.
3. Server pairing page and user-facing API messages.
4. C# tray, settings and dialogs (current).
5. Repository documentation and code comments translated to English.

French UI remains the default for French browsers. Existing saved profiles and configuration files are language-neutral.
