# Images, icons and animated GIF packs

Available starting with DeckEdge 0.1.6. Open a key's **Library** button in
the Studio. The library has three tabs: Emoji, My artwork and Available packs.

## Install or import

- **Available packs:** install PC applications, gaming platforms, or the offline
  animated controls pack. The first two download logos from Simple Icons.
- **Import images / GIFs:** select one or several PNG, JPEG, WebP, GIF, ICO or
  simple SVG files. Animated GIFs keep their animation.
- **Import ZIP pack:** select a downloaded ZIP containing supported images.
  Subfolders are supported. There is no required folder structure.
- In **My artwork**, filter by pack, search by filename, or show animations only.
  Select a visual to apply it to the key. Choose the normal or active/muted state
  before selecting. Use **Remove key artwork** to return to an emoji.

Imported files are stored locally in `media/` inside DeckEdge's data directory.
The paired phone loads them from the PC; it does not contact the pack provider.
Downloaded packs continue to work offline. Removing a library entry preserves
its file so existing keys, undo history and profile backups remain usable.

## Create and share a pack

Put images and/or GIFs into a ZIP, optionally with `pack.json` at its root:

```json
{
  "format": "deckedge-pack",
  "version": 1,
  "name": "My game icons",
  "source": "https://example.org/my-pack",
  "license": "MIT"
}
```

Example ZIP contents:

```text
pack.json
icons/My game.png
icons/My app.svg
animations/Recording.gif
```

In **My artwork**, choose a pack and click **Export this pack** to create a ZIP
ready to share. Profile JSON exports also embed the visuals actually used by
their keys, including active-state artwork. Old profile files remain supported.
When an export exceeds its visual size limit, export the packs separately.

## Limits

- Single visual: 8 MB, maximum 4096 pixels per dimension.
- Animation: at most 300 frames and 64 million pixels across all frames.
- ZIP upload: 32 MB compressed, 64 MB expanded and 200 visuals.
- Library: 2,000 listed visuals. Profile/pack export: 200 visuals, 20 MB of data.
- SVG: static paths and basic shapes only; scripts, external resources and
  embedded HTML are rejected. Archive paths are never extracted onto disk.

The catalogue is deliberately small. Any compatible downloaded ZIP can be
imported, including packs of individual game artwork or animated GIFs. DeckEdge
does not currently offer an online GIF search service.

PC/game platform logos come from [Simple Icons](https://simpleicons.org), whose
collection is [CC0](https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md).
Brand marks remain the property of their respective owners. The animated
controls are generated by DeckEdge and covered by the project's MIT license.
